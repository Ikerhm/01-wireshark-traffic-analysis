# 01-wireshark-traffic-analysis
Lab 01 Wireshark, the objective for this lab is to learn defensive (Blue Team) cibersecurity, focused on network capture, inspection and analysis using Wireshark. The objective is to learn to identify protocols, TCP/IP connections, analyze DNS queries and recognize suspicious traffic patterns.

This laboratory is part of my cybersecurity training and seeks to develop fundamental skills in traffic analysis, monitoring and threat detection.
